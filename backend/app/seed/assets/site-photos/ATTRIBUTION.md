# Demo site photographs

These twelve photographs stand in for real site records so the photo gallery,
the daily report and the project timeline have something to show. They are not
pictures of the seeded projects — those projects are fictional.

Every file is used under a free licence. Attribution is kept here rather than
in the database because the records are demo data and get wiped on every reseed.
